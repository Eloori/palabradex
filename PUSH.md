# Veröffentlichen

1. Auf github.com ein neues, leeres Repository **palabradex** anlegen (public, ohne README).
2. Im Terminal:

```bash
cd ~/Projects/palabradex
git push -u origin main
```

3. Auf GitHub: Settings → Pages → "Deploy from a branch" → main / (root) → Save.

Nach 1 bis 2 Minuten ist die Seite online unter https://eloori.github.io/palabradex/
